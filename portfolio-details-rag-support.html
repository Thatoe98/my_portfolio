Project Overview

An AI customer-support bot for Facebook Messenger that answers from a business's own documents using retrieval-augmented generation, and — critically — knows when not to answer. When the retrieved context isn't confident enough to support an answer, the conversation escalates to a human supervisor over Telegram with the full chat transcript, and a simple /done command hands the conversation back to the bot once resolved.

Rather than reaching for a managed vector database, I built the retrieval layer myself with SQLite and NumPy: documents are chunked and embedded, and relevant chunks are retrieved by cosine similarity before being passed to Gemini 2.0 Flash for the final answer. A no-code admin webapp lets a non-technical business owner upload knowledge files, retrain the bot's behavior conversationally, and review past conversations and usage — changes apply to the live system prompt instantly, with no redeploy.

Core Modules

Custom RAG Engine

SQLite + NumPy embedding store with cosine-similarity retrieval — no external vector DB required.

Telegram Human Handoff

Low-confidence conversations escalate to a supervisor with full transcript, bridged back with /done.

No-Code Admin Webapp

Upload knowledge files and retrain behavior through chat, with instant effect on the live system prompt.

Messenger Integration

FastAPI backend serves the Facebook Messenger webhook and conversation state.

Technical Strengths

Confidence-Aware Routing

  • Bot answers directly only when retrieval confidence is high
  • Ambiguous or out-of-scope questions escalate instead of guessing
  • Full conversational context passed to the human supervisor

Built-From-Scratch Retrieval

  • Chunking and embedding pipeline without a managed vector DB
  • SQLite for persistence, NumPy for similarity scoring
  • Analytics and usage tracking surfaced in the admin panel

Skills Demonstrated

  • RAG From First Principles: Building a retrieval engine with SQLite + NumPy instead of defaulting to a managed vector store.
  • Human-in-the-Loop Design: Confidence-based escalation so the bot fails safely instead of hallucinating.
  • Full-Stack Product Thinking: A no-code admin layer that makes the system usable by a non-technical business owner.
  • Messaging Platform Integration: Facebook Messenger webhook handling and a Telegram operator bridge in one system.
