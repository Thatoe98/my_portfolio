Project Overview

A face-recognition API that identifies a person from a single photo by comparing its Facenet512 embedding against a reference gallery of 105 celebrity classes, served behind a lightweight Flask backend with DeepFace handling detection and embedding extraction.

Rather than training a classifier from scratch, the system treats recognition as a nearest-neighbor retrieval problem: every query face is projected into the same 512-dimensional embedding space as the reference set, and the match is decided by cosine distance to the closest known identity — the same approach that scales to open-set recognition where new identities can be added without retraining.

Core Modules

Face Detection

DeepFace's detector backend locates and crops the face region before embedding extraction.

Facenet512 Embeddings

Each face is projected into a 512-dimensional embedding space for similarity comparison.

Cosine-Distance Matching

Query embeddings are matched to the closest of 105 reference identities by cosine distance.

REST API

Flask exposes /predict for inference and /health for liveness checks.

Technical Strengths

Embedding-Based Design

  • Retrieval rather than classification — new identities can be added without retraining
  • Configurable distance threshold to tune precision vs. recall
  • Top-5 match ranking rather than a single hard prediction

Service Design

  • Clear project structure separating model loading, inference, and API layers
  • Configurable options for detector backend and distance metric
  • Health-check endpoint for deployment monitoring

Skills Demonstrated

  • Metric Learning Concepts: Using pre-trained face embeddings and distance thresholds instead of training a closed-set classifier.
  • Applied Deep Learning: Integrating DeepFace/TensorFlow models into a production-shaped inference path.
  • API Design: A minimal, documented Flask API with health checks for deployment.
  • Computer Vision Fundamentals: Face detection, alignment, and embedding extraction with OpenCV/DeepFace.
