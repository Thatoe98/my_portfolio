Project Overview

A banking-fraud analysis notebook built around a key constraint of real fraud data: there are no reliable labels to train a supervised classifier against. Instead of forcing a label that doesn't exist, I engineered behavioral features from raw transaction logs — amount-to-balance ratio, transaction frequency, and time-of-day patterns — and used unsupervised clustering to let normal spending behavior group itself, so that transactions falling outside those clusters surface as candidates for manual fraud review.

The emphasis throughout was on exploratory data analysis and feature engineering rather than treating the model as a black box: visualizing how legitimate transactions cluster, understanding why certain points fall outside those clusters, and being explicit about the approach's limits — an unsupervised flag is a prioritization signal for a human reviewer, not an automatic fraud verdict.

Core Modules

Feature Engineering

Derived behavioral signals — amount-to-balance ratio, transaction frequency — from raw banking logs.

Clustering for Normal Behavior

Groups typical spending patterns so that transactions outside those clusters stand out.

Outlier Scoring

Statistical distance-from-cluster scoring ranks transactions by how anomalous they are.

Exploratory Visualization

Seaborn scatter and distribution plots to interpret and validate why points were flagged.
