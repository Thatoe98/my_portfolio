Project Overview

Jarvis is an AI marketing-assistant platform that takes a short voice or text brief from an operator in Telegram and turns it into a ready-to-publish, bilingual (Burmese/English) Facebook post — built for a real restaurant client, Crimson Palace, that needed consistent social content without a dedicated marketing hire.

The pipeline is retrieval-grounded rather than purely generative: a pgvector knowledge base holds the client's menu, pricing, and brand voice, so the content agent (routed through LiteLLM to Gemini) retrieves relevant context before drafting a caption and image, instead of hallucinating details about the business. Nothing goes live without a human tapping Approve in Telegram — publishing happens through the Facebook Graph API only after that explicit sign-off.

Core Modules

Telegram Operator Interface

aiogram-based bot accepts a voice or text brief and drives the whole approval workflow.

pgvector Knowledge Base

Menu, pricing, and brand-voice context retrieved before generation to keep posts factually grounded.

Bilingual Caption + Image Generation

LiteLLM-routed Gemini calls produce Burmese and English captions alongside a matching image.

Human-in-the-Loop Publish Gate

Nothing posts without explicit Telegram approval; publishing goes through the Facebook Graph API.

Technical Strengths

Agentic Pipeline Design

  • FastAPI backend orchestrating retrieval, generation, and approval as discrete stages
  • LiteLLM abstraction keeps the pipeline model-agnostic (currently Gemini)
  • SQLAlchemy/Alembic migrations for a production-grade data layer

Safe Automation

  • RAG grounding reduces hallucinated menu/price claims
  • Mandatory human approval before any public post
  • Docker + docker-compose for repeatable deployment

Skills Demonstrated

  • Agentic System Design: Multi-stage pipeline from brief to retrieval to generation to gated publish.
  • RAG for Grounded Generation: pgvector retrieval to keep LLM output factually tied to real business data.
  • Human-in-the-Loop Automation: Designing an approval gate so automation augments rather than replaces judgment.
  • Production Engineering: SQLAlchemy/Alembic, Docker Compose, and a real deployed client system.
